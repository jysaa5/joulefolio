# Joulefolio - Codex Instructions

## Project Overview
This is a Next.js application for an energy portfolio platform.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Project Structure
- /src/app: routing pages
- /src/features: feature-based modules
- /src/entities: domain models
- /src/shared: common utilities

## Commands
- install: npm install
- dev: npm run dev
- test: npm run test

## Coding Rules
- Use functional components
- Use TypeScript strictly
- Keep components small and reusable
- Separate server state and client state

## Testing
- Use Vitest for logic testing
