# Joulefolio Overview

## 프로젝트명

- Joulefolio (줄폴리오)

## 서비스 정의

Joulefolio는 에너지 데이터를 실시간으로 시각화하고, 사용자 간 거래까지 연결하는 인터랙티브 에너지 플랫폼이다. 이 서비스는 에너지를 단순 소비 데이터가 아니라 자산으로 보고, 이를 포트폴리오 개념으로 확장한다.

## 서비스 아이디어

- 에너지 프로슈머(Producer + Consumer)를 위한 플랫폼
- 개인 간 에너지 거래(P2P Energy Trading)와 소셜 요소를 결합한 서비스
- 개인 태양광 발전 현황을 모니터링하고, 생산된 전력을 도매상 정산 구조를 통해 지인과 공유하거나 판매하는 에너지 커뮤니티

## 핵심 가치

- 투명성: 내 태양광 패널이 지금 얼마나 전력을 생산하는지 실시간으로 확인할 수 있다.
- 효율성: 남는 전력을 버리지 않고 가치와 수익으로 전환할 수 있다.
- 연결성: 도매상을 중개자로 활용해 친구나 가족에게 전력을 선물하거나 공유할 수 있다.

## 시스템 구조

에너지는 물리적으로 특정 사용자 집으로 직접 이동하는 것이 아니라, 전력 관리 데이터와 도매상 정산 구조를 통해 거래된다.

1. 생산: 유저의 태양광 패널과 배터리(ESS)에서 전력을 생산한다.
2. 측정: 센서 또는 API를 통해 앱에서 실시간 발전량과 배터리 잔량을 확인한다.
3. 중개: 앱에서 공유 또는 판매 요청이 발생하면 도매상이 해당 전력만큼을 유저로부터 매입한다.
4. 전달: 도매상이 수신자에게 전기요금 할인 또는 포인트 형태로 그 가치를 전달한다.

## 주요 기능

### 1. 태양광 인벤토리 및 정보

- 재료 및 장비 데이터베이스: 태양광 패널, 인버터, 배터리 등 구성 요소의 스펙과 가격 정보 제공
- 발전기 사전 계산: 위치와 장비를 선택하면 예상 발전량을 계산하는 시뮬레이터 제공

### 2. 대시보드

- 실시간 발전량 시각화: 현재 생산 전력량(W, kWh) 확인
- 배터리 상태: ESS 충전율 및 사용 가능 시간 표시
- 통계 리포트: 일간, 월간, 연간 발전 데이터 요약

### 3. 에너지 마켓 및 소셜

- 판매하기: 잉여 전력을 도매상에게 판매해 수익화
- 공유하기: 친구에게 전력 가치를 선물 또는 공유
- 도매상 연동: 거래 발생 시 중개 업체와 정산 데이터 교환

## 아이디어의 강점

- 시장 적합성: 분산형 에너지 자원(DER)과 가상 발전소(VPP) 흐름을 개인 사용자 수준으로 재해석한 모델
- 확장성: 탄소 배출권 거래, 친환경 제품 커머스로 확장 가능

## 전체 계획

### 1단계: 핵심 MVP

- 내 발전량 대시보드
- 에너지 생산 및 소비 그래프
- 잉여 에너지 계산

### 2단계: 거래 시스템

- 친구 추가
- 에너지 판매 요청
- 거래 상태 UI

### 3단계: 커뮤니티

- 피드
- 랭킹
- 활동 로그

### 4단계: 시각화 고도화

- 전기 흐름 애니메이션
- 거래 시 에너지 이동 표현
- 발전량 증가 시 UI 반응

## 단계별 범위

### 1차 MVP 범위

- 대시보드 정적 및 목업 데이터
- 거래 요청 플로우
- 커뮤니티 피드 UI
- 기본 상태 관리
- 반응형 레이아웃

이 범위만으로도 서비스 데모가 가능하다.

### 2차 확장

- mock API 연결
- 로그인
- 친구 목록
- 거래 내역
- 차트 데이터 필터
- 알림

### 3차 확장

- 실시간 데이터 반영
- 거래 승인 플로우
- 랭킹 및 배지
- 지도 기반 에너지 커뮤니티
- WebSocket 또는 SSE

## 제품 메모

- 캐시워크처럼 단순 행동을 통해서도 에너지를 저장하거나 절약하고, 이를 금전적 가치로 연결하는 방향성도 후속 실험 아이디어로 유효하다.
