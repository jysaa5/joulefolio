# Joulefolio Screens

## 랜딩 페이지

### 목적

- 서비스의 메시지를 빠르게 이해시키고 핵심 행동으로 진입시킨다.

### 문구 후보

- 당신의 행동이 에너지가 됩니다.
- 전기를 아끼거나 생산하면 에너지 포인트가 쌓이고 현금처럼 사용할 수 있습니다.

## 메인 대시보드

### 화면 목표

- 내 에너지 상태를 한눈에 이해하게 한다.
- 현재 잉여 전력 여부를 보여준다.
- 거래 화면으로 자연스럽게 이어지게 한다.

### 핵심 UI

- 오늘 발전량
- 오늘 소비량
- 현재 잉여 전력
- 이번 주 발전 추이 그래프
- 배터리 및 저장 상태
- 거래 가능 에너지 카드
- 판매하기 버튼
- 지인에게 공유하기 버튼

### 섹션 구조

- 상단: 내 집 또는 내 발전소 요약 카드
- 중단: 발전량 vs 소비량 차트
- 하단: 거래 가능 전력, 최근 거래 내역, 커뮤니티 소식 미리보기

### 사용자 액션

- 발전 데이터 자세히 보기
- 기간별 조회
- 거래 화면으로 이동
- 커뮤니티 글 보기

### UX 포인트

- 차트가 많아질 경우 렌더링 최적화가 필요하다.
- 실시간처럼 보이게 하려면 polling 또는 mock stream 구조가 필요하다.
- 숫자만 표시하지 않고 색상, 아이콘, 짧은 상태 문장으로 해석해야 한다.
- 예시 문구: 현재 3.2kWh 잉여 전력이 있어 거래할 수 있어요.

### 화면 구성 예시

- Header: `Joulefolio`
- Portfolio Summary: 총 에너지 자산, 오늘 수익
- Chart: 생산량 vs 소비량 그래프와 요약 수치
- Energy Breakdown: 소비, 저장, 판매 가능
- CTA: 에너지 판매하기
- Recent Activity: 거래 내역, 최근 커뮤니티 활동

## 거래 화면

### 화면 목표

- 에너지 거래를 쉽게 느끼게 한다.
- 거래 과정을 복잡하지 않게 만든다.
- 거래 대상과 상태를 명확히 보여 신뢰감을 준다.

### 핵심 UI

- 현재 판매 가능 전력
- 거래 대상 선택
- 거래 방식 선택
- 거래 수량 입력
- 예상 금액 표시
- 거래 요청 버튼
- 거래 상태 카드

### 거래 방식

- 지인에게 공유
- 커뮤니티 마켓에 판매

### 거래 상태

- 요청됨
- 수락 대기
- 완료
- 취소

### 섹션 구조

- 상단: 판매 가능 에너지 요약
- 중단: 거래 폼
- 하단: 최근 거래 내역과 거래 상태 타임라인

### 사용자 액션

- 판매할 전력량 입력
- 받는 사람 선택
- 거래 완료 후 상태 확인
- 거래 취소 또는 수정

### 상태 설계 제안

거래 화면은 단순 입력 폼보다 상태 전이가 있는 흐름으로 설계하는 것이 적합하다.

- `idle`
- `editing`
- `validating`
- `pending`
- `success`
- `failed`

이 상태 설계를 통해 버튼 비활성화, 에러 메시지, 로딩 상태, 완료 애니메이션 같은 인터랙션을 일관되게 처리할 수 있다.

### UX 포인트

- 사용 가능한 전력보다 많은 값을 입력하면 즉시 경고
- 거래 후 에너지 흐름 애니메이션 제공
- 예상 정산 금액을 실시간 계산
- 상대방 프로필과 신뢰도 표시

### 화면 구성 예시

- Header
- Available Energy: 판매 가능 6.3kWh
- Trade Form: 대상 선택, 거래량 입력, 예상 금액 표시
- Action: 거래 요청하기
- Trade Status List: 요청됨, 완료됨, 취소됨

## 커뮤니티 화면

### 화면 목표

- 사람 간 연결을 만든다.
- 친환경 활동에 대한 동기와 재미를 강화한다.
- 거래와 관계를 하나의 플랫폼 경험으로 연결한다.

### 핵심 UI

- 피드 목록
- 지인 활동 카드
- 오늘의 친환경 랭킹
- 누적 절감량 및 탄소 절감량
- 거래 후기
- 에너지 나눔 인증 글

### 예시 콘텐츠

- 오늘 태양광으로 5.1kWh 생산했어요.
- 남는 전력을 이웃에게 공유했어요.
- 이번 달 탄소 절감량 상위 10%예요.

### 사용자 액션

- 글 작성
- 좋아요
- 댓글
- 친구 추가
- 거래 상대 탐색

### 왜 중요한가

거래 기능만 있으면 서비스가 건조하게 느껴질 수 있다. 커뮤니티를 통해 내 활동이 사회적 의미와 관계를 갖는 행동처럼 인식되도록 만든다.

### UX 포인트

- 카드형 피드 UI
- 활동 배지 시스템
- 사용자별 성과 시각화
- 필터: 친구만 보기, 우리 동네 보기, 거래 후기만 보기

### 화면 구성 예시

- Header
- Feed Card: 사용자 이름, 생산량, 내용, 좋아요
- Filters: 친구만 보기, 전체 보기
- CTA: 글 작성하기

## 화면 간 연결 구조

세 화면은 독립 화면이 아니라 하나의 흐름으로 연결된다.

- 대시보드: 현재 상태 확인
- 거래: 판매 또는 공유 실행
- 커뮤니티: 결과 공유 및 다른 사용자 활동 탐색

### 기본 사용자 흐름

1. 대시보드에서 잉여 전력을 확인한다.
2. 거래 화면에서 판매 또는 공유를 진행한다.
3. 커뮤니티에서 결과를 공유하거나 다른 사용자 활동을 확인한다.
